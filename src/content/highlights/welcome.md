This is a placeholder highlight entry. Replace this content with your own.

To create another highlight, add a new `.md` (or `.mdx`) file in this directory
(`src/content/highlights/`). The file name becomes the entry id, and the
frontmatter `date` controls its position in the masonry layout.

Optional frontmatter fields passed through to the card renderer:
- `images: [{ src, alt }]` — local path under `src/assets/**` or an `https://` URL
- `video: { src, alt, poster }` — same source rules as images
- `external: { uri, title, description, thumb }` — link preview card
- `link` — wraps the card in a click-through
- `tags` — list of strings, shown at the bottom of the card
